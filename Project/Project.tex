\section{Goal (Current Thought)}

\begin{itemize}
    \item[1.] Show that prolongated associativity operad $\PP\mathscr{M}$ is well-defined as a $G$-operad.
    \item[2.] Promoe $\PP\mathscr{M}$ promotes to a well-defined permutativity $G$-operad in $\Cat_G$ (say $\mathscr{E}\PP\mathscr{M}$), and use it to define the new pseudoalgebras. 
    \item[3.] Show that $\mathscr{F}_{G,\RR}$ pseudofunctors (if possible, $G$-functors, meaning preserving morphism sets' $G$ equivariance) is well-defined, together with isomorphism to new pseudoalgebras as above.
    \item[4.] (Not sure if it's true), but if we can show there is an equivalence of $G$-categories between the original $\mathscr{P}_G$ and $\mathscr{E}\PP\mathscr{M}$, then maybe we cn also show the equivalence from the original categories.
\end{itemize}

The first three goals based on intuition and inspection seems to be true.
